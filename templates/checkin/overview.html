helpHow it works

{% if QR_ON %}

QR stickers

  1. Give people a QR code on their profile, or many at once from Print stickers.
  2. Print the stickers and put each one inside the person's Bible.
  3. At the door, open the kiosk on a tablet, laptop or phone and log in as an usher or the kiosk account. A USB QR scanner works too.
{% endif %} {% if FACE_ON %}

Face at the kiosk

  1. Record the person's signed consent on their profile, then Enroll face (5 pictures, 10 seconds). {{ faces }} enrolled so far.
  2. At the kiosk they simply look at the camera.
{% endif %} {% if TERMINALS_ON %}

Door terminal

  1. Record consent and Register on terminals on their profile, then enroll their {% if FINGERPRINT_ON %}finger{% endif %}{% if FINGERPRINT_ON and FACE_ON %} or {% endif %}{% if FACE_ON %}face{% endif %} at the terminal.
  2. Set up and approve terminals under Door terminals.
{% endif %}

Every way checks them into the service happening at that time. The service opens automatically.

shield_personPrivacy

  • The QR holds only a random code, never a name or other personal details. A lost sticker? Make a new code on their profile.
    • {% if TERMINALS_ON %}
  • Fingerprints and faces need the person's signed consent (RA 10173). Withdrawing it removes them from the kiosk and every terminal.
    • {% endif %} {% if FACE_ON %}
  • The kiosk keeps numbers computed from a face, never a photo.
    • {% endif %}
